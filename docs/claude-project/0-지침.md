이 프로젝트는 `fish-444/non-competitive` 의 `alocasia-farm` — 사진 한 장으로 온실을
재는 FastAPI + three.js 웹앱이다. 알로카시아 관엽에서 시작해 **작물 온실**로 넓히는 중이다.

## 답할 때

- **한국어로.** 코드 주석·문서·커밋 메시지 전부 한국어다.
- 주석은 **무엇이 아니라 왜**를 적는다. 이 저장소의 기존 주석을 보고 밀도와 말투를 맞춘다.
- 추측을 사실처럼 말하지 않는다. 모르면 "확인이 필요하다"고 하고, 확인할 방법을 알려 준다.

## 고칠 때 반드시

```bash
cd alocasia-farm
for f in test_*.py; do python "$f"; done   # 450개, 전부 통과해야 한다
python bench_real.py                        # 화분 오차 0, 잎 오차 3 (이 아래로만)
```

`bench_real.py` 가 중요하다. `test_*.py` 는 "규칙대로 도는가"만 보는데, 그룹화 규칙은
규칙대로 돌면서도 실제 사진에서 틀릴 수 있다. **그룹화를 건드렸으면 재고 나서 말한다.**

## 절대 커밋 금지

`farm_env.bat` / `farm_env.sh`(API 키) · `farm.db`(사용자 기록) · `bench_data/`.
셋 다 `.gitignore` 가 막고 있다. 예제 파일에도 키를 적지 않는다 — 전에 실제로
공개 저장소에 올라가 키를 폐기한 적이 있다.

## 이 코드가 지키는 선

1. **모르면 숫자를 만들지 않는다.** 근거 없는 날짜가 화면에 뜨면 사람은 그걸 믿고 준비한다.
   기록이 모자라면 "아직 모릅니다"라고 말하고, 왜 모르는지와 무엇을 하면 알 수 있는지를 적는다.
2. **설정을 안 건드린 사람에게는 아무것도 안 바뀐다.** 새 기능은 기본값이 '예전 그대로'여야 한다.
3. **추정을 측정처럼 말하지 않는다.** 노지 격자값을 화분 값으로, 어림값을 실측처럼 쓰지 않는다.
   어쩔 수 없이 어림하면 화면에 그렇게 적는다.
4. **잠정값은 잠정값이라고 적는다.** 원예 통념에서 잡은 수치는 `provisional` 로 표시한다.

## 브랜치

`main` 에서 작업한다 — `alocasia-farm/install.ps1` 이 `$Branch = 'main'` 을 보고
설치하므로, 옆 브랜치에 올리면 사용자가 설치해도 그 변경이 안 따라온다.
(작업용 브랜치를 따로 쓰는 중이면 끝나고 `main` 에 합친다.)
