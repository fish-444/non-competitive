# 1. 이 앱이 무엇인가 · 작업 규칙

## 한 줄

**사진 한 장으로 온실 전체를 재는 웹앱.** 탑뷰 사진을 올리면 잎을 탐지해 포기별로
묶고, 잎 수·크기 등급·물 준 날을 기록하고, 3D 온실로 그려 준다. 빛이 덜 드는 자리를
찾아 화분 배치를 다시 짜 주기도 한다.

## 어디까지 왔나

| 단계 | 무엇 |
|---|---|
| 처음 | 알로카시아 관엽 전용. 사진 → 잎 탐지 → 3D 온실 + 이름 커스텀 |
| 쌓임 | 화분 자리 고정, 원근 보정, 잎 낱개 신원, 물주기 프로필, 배치 최적화, 성장 이력 |
| **작물** | 화분마다 작물(상추·바질·딸기…)을 적으면 물주기·등급 기준·필요 광량이 그 작물 기준으로 |
| **수확** | 생장 이력의 기울기로 수확적기와 예상 생산량 예측 |
| **기상** | 온실 위치를 넣으면 바깥 날씨를 **재배 환경만큼만** 반영 |

방향이 한 번 꺾였다. 알로카시아는 "센서·날씨 API 없이" 가 명시적 설계였다(거실
선반은 냉난방이 걸려 바깥이 잘 안 넘어온다). **작물 온실은 그 전제가 다르다** —
비닐하우스는 바깥 기온이 거의 그대로 들어온다. 그래서 날씨를 보되, 얼마나 볼지는
사용자가 재배 환경으로 선언한다.

## 무엇으로 만들었나

- **뒤**: 파이썬 + FastAPI. 외부 의존은 `fastapi` `uvicorn` `python-multipart` `pillow` `requests` 뿐.
- **앞**: 브라우저 + three.js (동봉, CDN 안 씀).
- **탐지**: 로보플로우 워크플로(기본). `providers/` 로 갈아 끼운다. 키가 없으면 데모 난수로 착지.
- **기상**: Open-Meteo(키 불필요, 기본) 또는 기상청 단기예보(키 필요).
- **저장**: `farm.db` (SQLite 한 테이블에 JSON 덩어리).

## 돌리는 법

```bash
cd alocasia-farm
python3 -m pip install -r requirements.txt
python3 -m uvicorn main:app --reload --port 8123
# http://127.0.0.1:8123
```

키는 `farm_env.bat`(맥·리눅스는 `farm_env.sh`)에서 앱이 직접 읽는다. 없으면 앱이
만들어 준다. **`--port` 를 빼면 8000 으로 뜬다** — 바탕화면 바로가기(8123)로는 안 열린다.

## 고치고 나면 반드시 두 가지

```bash
cd alocasia-farm
for f in test_*.py; do python "$f"; done   # 450개
python bench_real.py                        # 실제 사진 정확도
```

테스트는 **전부 네트워크 없이** 돈다. 새로 쓰는 테스트도 그래야 한다 — 네트워크를
타는 부분은 가짜 응답으로 대신한다.

`bench_real.py` 는 v8 모델로 받아 둔 실제 사진 자료로 잰다. 현재 성적은 **화분 오차 0,
잎 오차 3**. 잎 3장은 모델이 아예 못 낸 것이라 코드로는 못 줄인다 — 후처리는 모델이
낸 박스를 하나도 안 흘린다.

> 그룹화 규칙은 "규칙대로 돌면서도 실제 사진에서 틀릴" 수 있다. 실제로 그럴듯해
> 보이는 규칙(중복 캐노피 정리, 잎과 같은 박스인 캐노피 제거)을 넣었다가 벤치마크가
> 더 나빠져서 되돌린 적이 있다. **그룹화를 건드렸으면 재고 나서 말한다.**

## 절대 커밋 금지

| 파일 | 왜 |
|---|---|
| `farm_env.bat` / `farm_env.sh` | 로보플로우·기상청 API 키. 전에 실제로 공개 저장소에 올라가 키를 폐기했다 |
| `farm.db` | 사용자의 식물 기록 |
| `bench_data/` | 각자 다른 사진으로 만든 측정 자료 |

`farm_env.example.bat` 같은 견본에도 키를 적지 않는다. 애초에 견본 파일을 없애고
**앱이 `farm_env.bat` 을 직접 만들도록** 바꾼 이유가 이것이다 — 견본을 고쳐 놓고
왜 키가 안 잡히냐고 하거나, 견본에 키를 적어 올리는 사고가 반복됐다.
