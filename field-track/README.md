노지 재배 작물의 **수확 시기와 출하 분포**를 예측합니다.
대상 작물: 상추(노지), 방울토마토(노지).

---

## 왜 별도 트랙인가

시설(온실) 트랙과 **모델의 구조가 반대**입니다.

```
시설 트랙:  제어 입력 → [온실 물리모델] → 환경 → [Crop Pack]
노지 트랙:  기상 관측/예보 →              환경 → [Crop Pack]
                                            ↑
                                  여기에 생장곡선 / DSSAT
```

온실은 기상이 제어의 *결과*라 계산 대상입니다. 노지는 기상이 **외생 입력**이고 계산 대상이 아닙니다.
그래서 온실 물리모델을 확장하는 것이 아니라 처음부터 다른 트랙입니다.
