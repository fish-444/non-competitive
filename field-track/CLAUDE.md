# 작업 규칙 — 노지 트랙

이 규칙들은 실제 작업에서 실패를 겪고 정해진 것입니다. **어기면 되돌리기 어렵습니다.**
코드를 쓰기 전에 읽으세요.

주석과 커밋 메시지는 한국어로 씁니다. 주석은 '무엇'이 아니라 **'왜'**를 씁니다.

---

## 1. 숫자를 지어내지 않는다

근거 없는 값은 `confidence: "low"` + `source: null`로 두고 미확보 목록에 올립니다.
**빈칸은 안전하지만 틀린 값은 위험합니다.** 플랫폼이 잘못된 농업 판단을 하면 작물이 죽습니다.

잠정값에는 `"provisional": true`를 붙이고 **왜 잠정인지** 함께 씁니다.

출처는 페이지까지 적습니다.

```
"source": "한국농업기술진흥원, 노지작물 생육정보 메타데이터 ― 제3부: 배추(SPS X KOAT 0017-7534:2022), p.4"
```

## 2. 신뢰도는 사람만 올릴 수 있다

| confidence | 조건 |
| --- | --- |
| `high` | **현장 전문가가 검증함. 사람만 부여** |
| `medium` | 출처가 명확한 문헌값 |
| `low` | 근거 미확보 또는 추정 |

**웹 조사나 논문만으로는 최고 `medium`입니다.**
`reviewStatus: "expert_approved"`도 사람만 부여합니다.

## 3. 실측이 문헌을 덮어쓰지 않는다

실측은 `observedRange`로 **병기**합니다. 문헌값을 지우지 마세요.
표본이 작고, 센서가 고장났을 수 있고, 품종·재배방식이 다를 수 있습니다.

**어긋나는 것 자체가 정보입니다.** 어긋나면 그 사실을 기록해 전문가 검토 항목으로 올립니다.

## 4. 작물 종속 개념을 스키마 필드명에 박지 않는다

방울토마토는 화방 단위로 개화·수확이 반복됩니다. 이걸 `truss`나 `화방`이라는 필드명으로
스키마에 넣으면 **상추가 안 들어갑니다.** 상추는 화방이 없습니다.

범용 이름을 씁니다. 새 필드를 만들 때마다 **"상추와 방울토마토 둘 다에 말이 되는가"**를 확인하세요.

> 시설 트랙에서 이미 이 실수가 있었습니다. `per_truss` / `truss_number` /
> `planned_truss_count`가 JSON·TS·DB 전반에 박혀 있습니다.
> 이 저장소에서는 반복하지 않습니다. 명명 후보는 `docs/결정대기.md` D-4 참조.

## 5. 기본값은 아무것도 바꾸지 않는 수준으로

설정을 건드리지 않은 사용자에게 기존 동작이 그대로 유지되어야 합니다.

## 노지 특유의 주의

### `controllable: false`가 기본값이다

노지는 대부분 제어 불가입니다. 시설의 `controlLevel` 개념을 그대로 가져오면 안 됩니다.
관수·멀칭·터널처럼 제어 가능한 항목만 개별적으로 `true`를 줍니다.

### 적산온도(GDD)를 아무 데나 쓰지 않는다

작물·현상마다 통하는 구간이 다릅니다. **누적형인지 구간반응형인지 먼저 판단**하고
`detection.method`를 구분합니다.

| method | 쓰는 곳 |
| --- | --- |
| `thermal_time` | 적산온도 누적이 통하는 구간 |
| `temp_window_exposure` | 특정 온도대 노출이 필요한 단계 (춘화, 화아분화) |
| `morphology` | 형태 관측 |
| `calendar_offset` | 추정치. 다른 방법이 없을 때만 |
| `manual` | 사람이 지정 |

딸기 화아분화가 대표적 반례입니다. 12~14℃ 노출이 필요하고 **30℃를 한 번 넘으면
그동안 쌓인 게 무효**가 됩니다. GDD로 짜면 틀립니다.

배추 추대도 마찬가지입니다. **저온 노출(유도) → 고온·장일(발현)의 2단계**입니다.
상추가 같은 구조인지는 **아직 확인되지 않았습니다.**

### 미래 기상을 단일값으로 쓰지 않는다

반드시 평년 다년 앙상블로 돌려 결과를 **분포(중앙값 + 범위)**로 냅니다.
"8월 12일 수확"이 아니라 **"8월 8~17일, 중앙값 12일"**입니다.

이것이 예측 오차의 최대 원인이므로 **화면에 불확실성 범위를 반드시 표시합니다.**

### 지표가 순간값인지 누적값인지 먼저 분류한다

시설 트랙에서 착과수를 중앙값으로 문헌과 비교했다가 틀린 일이 있습니다.
착과수는 순간값이라 비교 대상이 **최댓값**이었습니다.

각 지표를 순간값/누적값으로 먼저 분류하고 **그 분류를 코드 주석에 남기세요.**
조사 정의를 모르면 결론을 내리지 말고 `UNRESOLVED`로 표시합니다.
