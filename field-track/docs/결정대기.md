### D-6. 노지용 `controlLevel` 등급이 필요한가

현재 등급은 1(표시만) → 5(자동실행), 기본 2입니다.
노지는 대부분 `controllable: false`라 **3~5가 원리적으로 도달 불가**입니다.

- **(가) 기존 등급 유지, 노지 팩은 1~2만 사용** — 스키마 변경 없음. **권장**
- (나) 노지용 등급 신설 — 스키마가 갈라짐

관수·멀칭·터널 개폐처럼 노지에도 제어 가능한 항목이 있어,
`controllable`을 항목별로 쓰면 5단계 척도가 그대로 성립합니다.

**상태:** 미정. (가) 권장

### D-7. 상추 추대의 유도 기작 — 문헌 조사 항목

배추는 저온 유도형입니다(저온 노출 → 고온·장일 발현의 2단계).
**상추가 같은지는 확인되지 않았습니다.** 배추는 십자화과, 상추는 국화과입니다.

Phase 1-2를 짜기 전에 필요한 것:

- 상추 추대가 저온 요구(춘화)형인가, 고온·장일 반응형인가
- `detection.method`가 `temp_window_exposure`인가 `thermal_time`인가 둘의 조합인가
- 임계값 (온도대·노출시간·일장)

**임계값을 못 찾으면 `provisional: true` + `confidence: "low"`로 두고 민감도만 잽니다. 지어내지 않습니다.**

**상태:** 미조사

### ✅ D-5. 노지 트랙의 언어 — 파이썬 (2026-08-14 해소)

처음에 "기존 레포는 TypeScript 단일 스택이라 파이썬을 새로 들여야 한다"고 적었으나
**틀렸습니다.** 시설 트랙(`dreaming`)만 보고 판단한 것이고, 노지 트랙이 실제로 사는
이 저장소는 파이썬입니다 — `alocasia-farm/requirements.txt`, `light-sim/`, `greenlight/` 전부.

따라서 **파이썬으로 갑니다.** 지시문의 "`requirements-field.txt`로 분리해
기존 `requirements.txt`를 오염시키지 마세요"도 말 그대로 읽으면 됩니다 —
보호해야 할 기존 파이썬 스택이 실재합니다.

Phase 1 진입 시 `field-track/requirements.txt`를 따로 두고
`alocasia-farm/requirements.txt`는 건드리지 않습니다.

### ✅ 노지 트랙 저장소 위치 (2026-08-14 해소)

`fish-444/non-competitive` 저장소의 **`field-track` 브랜치**, `field-track/` 디렉터리에 둡니다.
처음에는 `C:\Users\sho36\field-track`에 독립 저장소로 만들었으나,
원격이 이미 붙어 있는 저장소로 옮기는 편이 나아서 같은 날 흡수했습니다.

`alocasia-farm`과 한 저장소를 쓰지만 브랜치가 다릅니다.
저장소 루트 `CLAUDE.md`의 "`main`에서 작업한다"는 **alocasia-farm 설치 스크립트가
`main`을 보기 때문**이고, 이 트랙에는 해당하지 않습니다.

GitHub 원격은 `origin`(`https://github.com/fish-444/non-competitive.git`)이 이미 있습니다.
다만 **push는 아직 못 합니다** — `gh` 토큰이 만료 상태(`fish-444` 계정)이고
`gh auth login`이 대화형이라 자동으로 처리할 수 없습니다. 재인증 후 올립니다.
